# Manuscript and project status

## Project

NMC-Census 2021 Register Rebuild

## Purpose

This repository provides disclosure-safe R code for rebuilding the March 2021 NMC Register extract within the ADR UK NMC–Census 2021 linked dataset.

## Current status

- Code: complete / under refinement
- OSF project: created
- GitHub repository: in preparation
- Zenodo archive: pending first release
- Manuscript: in preparation
- Data sharing: not permitted; restricted-access administrative data only

## Authors

- Michelle Jamieson
- Iain Atherton

## Notes

The repository contains code and documentation only. It does not contain individual-level NMC Register data, Census data, linked administrative data, or unreviewed outputs.

The underlying data are restricted-access administrative data available only through the ONS Secure Research Service under approved governance arrangements.
